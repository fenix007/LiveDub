Ключи API

Ключи хранятся только в этом профиле Chrome (chrome.storage.local), не синхронизируются и уходят только в API своего сервиса. Для распознавания нужен Deepgram или сервер LiveDub с SpeechKit; без остальных ключей перевод выполняет встроенный переводчик Chrome.

Deepgram — распознавание речи
console.deepgram.com → API Keys
Сервер LiveDub — распознавание Yandex SpeechKit SpeechKit принимает поток только по gRPC, поэтому звук идёт через server.js (npm install, затем make start). Ключ SpeechKit с ролью ai.speechkit-stt.user хранится на сервере.
DeepSeek — финальный перевод
Yandex Cloud — Translate и SpeechKit Роли: ai.translate.user для перевода, ai.speechkit-tts.user для озвучки.
